# Third-Party Notices

## Runtime

- `src/veriarbor` uses only the Python standard library.
- `apps/promotion_studio` uses only the Python standard library at runtime.

No Postiz, AGPL, vendored social-platform SDK, or third-party GUI framework
source is included in this preview.

## Development and testing

- The application tests use `pytest` as a development-only dependency.
- The library tests use `unittest` from the Python standard library.

Development dependencies are not bundled in the release archives.

## Assets

No third-party images, fonts, browser profiles, or platform assets are included.
The application's local test data is excluded from the release.
